## Sobre

Portfólio pessoal e blog de Felipe Gusmão. Aqui estão meus projetos, análises e anotações sobre dados e tecnologia.

Comecei minha jornada em dados pela Rocketseat e desde então venho desenvolvendo projetos práticos com datasets reais — de sistemas financeiros a análises de mercado imobiliário. Atualmente focado em aprofundar minha prática com Python, SQL e storytelling com dados.
