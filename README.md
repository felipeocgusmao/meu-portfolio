# Felipe Gusmão — Portfólio

Portfólio pessoal e blog de Felipe Gusmão, Data Analyst. Aqui estão meus projetos, análises e anotações sobre dados e tecnologia.

**Site:** [felipegusmao.vercel.app](https://felipegusmao.vercel.app)

## Stack

- [Astro](https://astro.build) — framework principal
- [Tailwind CSS](https://tailwindcss.com) — estilização
- [TypeScript](https://www.typescriptlang.org) — tipagem
- Deploy via [Vercel](https://vercel.com)

## Rodando localmente

```bash
pnpm install
pnpm dev
```

O servidor sobe em `localhost:3000`.
