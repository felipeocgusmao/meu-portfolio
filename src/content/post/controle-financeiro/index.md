## Sobre o projeto

Meu primeiro projeto prático de análise de dados — um sistema de controle financeiro completo com análise em Python e uma interface visual interativa para acompanhar receitas, despesas e saldo.

O projeto combina duas frentes: a análise feita em Jupyter Notebook e uma interface web para visualizar os dados de forma acessível.

## O que foi construído

### Análise de dados com Python

O coração do projeto é o notebook `Financial_Control_System_with_Colors.ipynb`, onde toda a lógica de análise acontece:

- Organização e categorização das transações financeiras
- Cálculo de saldos, totais por categoria e variações ao longo do tempo
- Visualizações com uso de cores para facilitar a leitura dos dados
- Exportação dos resultados para consumo na interface web

### Interface web

Uma dashboard construída do zero com HTML, CSS e JavaScript para visualizar os dados de forma intuitiva:

- Layout responsivo planejado no Figma antes de ser codado
- Estilização com CSS puro, incluindo paleta de cores para diferenciar categorias financeiras
- Interatividade com JavaScript para filtros e atualizações dinâmicas

## O que aprendi

Esse projeto foi importante para consolidar conceitos fundamentais que uso até hoje:

**No lado da análise:**
- Como estruturar um notebook de forma legível e documentada
- Manipulação de dados com pandas e visualizações com matplotlib
- A importância de limpar e validar os dados antes de qualquer análise

**No lado do desenvolvimento web:**
- Como transformar um protótipo do Figma em código real
- Organização de CSS sem frameworks
- Como conectar lógica de JavaScript a elementos visuais
